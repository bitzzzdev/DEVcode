Search through existing issues in bitzzdev/DEVcode using the glab cli to find issues matching this query:

$ARGUMENTS

Consider:

1. Similar titles or descriptions
2. Same error messages or symptoms
3. Related functionality or components
4. Same feature requests or bugs

Please list any matching issues with:

- Issue number and title
- Brief explanation of why it matches the query

Use `glab issue list --search "<query>"` and read matching issues with `glab issue view <number>`.
